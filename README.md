# OTel Contrib Atlas

An interactive, map-based guide to [opentelemetry-collector-contrib](https://github.com/open-telemetry/opentelemetry-collector-contrib): a component catalog, data-flow pipeline map, code architecture map, contribution workflow, and glossary — all driven by a committed extractor snapshot and deployed to GitHub Pages.

Bootstrap in progress. The blueprint lives in [plans/otel-contrib-atlas.md](./plans/otel-contrib-atlas.md).
